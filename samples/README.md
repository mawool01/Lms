# Sample SCORM packages

Two small packages for trying out SCORM support (a 3-question cell biology check, pass mark 70%):

- `sample-scorm12.zip` — SCORM 1.2
- `sample-scorm2004.zip` — SCORM 2004 (4th edition)

Upload them from a course's outline (**📦 SCORM** button on any module). They report score, pass/fail,
time spent and suspend data, and support "Save & exit" to resume later.
